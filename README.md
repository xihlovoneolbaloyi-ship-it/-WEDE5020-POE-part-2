# 📖 Project Overview

Sweet Crumbs Bakery is a modern, responsive bakery website developed as part of the **WEDE5020 Web Development Portfolio of Evidence (PoE)**.

The project demonstrates the practical application of front-end web development technologies while following user-centred design principles, responsive web design standards, and professional software development practices.

The website provides visitors with an engaging digital experience where they can:

- Learn about the bakery
- Browse bakery products
- Explore bakery services
- View image galleries
- Submit enquiries
- Contact the bakery
- Access branch information
- Navigate seamlessly across devices

The website has been designed with usability, accessibility, responsiveness, and maintainability as primary objectives.
